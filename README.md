# ZouYe Portfolio

A static personal portfolio: architecture, AI projects and practice notes.

## Deployment

- GitHub Pages: publish the `main` branch from `/(root)`. The site uses relative links and includes `.nojekyll`.
- Vercel: import the same GitHub repository and deploy the repository root. No build or environment variables are required.

The site includes the three browser demos embedded on the case pages. It does not include their standalone development repositories.
